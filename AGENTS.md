# Repository Instructions

- Do not commit planning, specification, or agent working documents to this repository. Keep them outside the repository or in the already-ignored `.superpowers/` and `docs/superpowers/` paths.
- Keep `main` synchronized with `origin/main` and free of local topic commits.
  Fetch and compare ahead/behind state before tracked-file changes. Do task work
  on a feature branch or managed worktree based on the latest `origin/main`, then
  fetch again before integration or push. Do not bypass the local branch guard.
